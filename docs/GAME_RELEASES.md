# ArcadeX — Public game release changelog

ArcadeX is a **multi-game Mini App** on MiniPay. Individual titles are not separate Mini Apps; they ship inside one arcade shell.

**MiniPay app (all games):**  
https://link.minipay.xyz/miniapp?id=4f8ff9f8-7eee-4fc9-ba0e-aad06b094d39

**Web app:** https://arcadex.trenchverse.com

**App launch date:** 2026-09-23  
ArcadeX went live on MiniPay on **23 September 2026**, shipping with the first five games listed below.

## How release dates are recorded

| Field | Meaning |
| --- | --- |
| **Public release date** | When the game became playable in the public arcade (`newArrivalAt` when set; otherwise catalog `createdAt`) |
| **Catalog created** | When the game entry was first added in admin (`createdAt`) |

Source of truth: ArcadeX game catalog in Firestore (exported for this public changelog).  
This file is the GitHub-visible evidence of ship dates for grant / milestone review.

Going forward, every new public game is added here on the same day it goes live, and we cut a matching GitHub Release when practical.

## Notes for reviewers

1. ArcadeX is one MiniPay Mini App with many games — there is **one** MiniPay listing URL for all titles above.
2. Game metadata (name, visibility, public go-live timestamp) lives in the ArcadeX catalog. Unity builds are served via CDN; that is hosting only and is separate from release dating.
3. **App launch date: 2026-09-23.** Orbit Flow, Dot Connect, BaseDrop, Block Blast, and Line Link — **5 games** shipped together at launch. Later titles use explicit public go-live stamps (`newArrivalAt`).
4. This changelog will be updated on each new public game ship.
